# پیش‌فایل | Pish File

**اپلیکیشن اندروید مدیریت پیش‌فروش املاک** — پروژه‌ها، واحدها، مشتریان و پیش‌فایل‌ها را یک‌جا ساماندهی کنید. کاملاً آفلاین، فارسی و راست‌چین.

> 📱 **وضعیت:** نسخه ۰.۵.۰ — بخش واحدهای آماده، پیوست فایل/عکس/ویدیو، متراژهای پروژه با شرایط مالی جداگانه، پروژه‌های سهامی با واریزی/امتیاز، پرداخت خودکار اقساط سررسیدشده و بازطراحی همه‌ی بخش‌ها به سبک بازی‌گونه؛ هسته‌ی آفلاین کامل و قابل نصب است.

## چرا پیش‌فایل؟

دفترهای کاغذی، فایل‌های اکسل پراکنده و یادداشت‌های گوشی برای پیگیری پیش‌فروش املاک کافی نیستند. پیش‌فایل برای این ساخته شده که فیلدهای تخصصی این کار — متراژ، بلوک، طبقه، پارکینگ، انباری، پیش‌پرداخت، اقساط، تعهدات و تاریخ سند — را در یک ساختار منظم نگه دارد و همیشه جواب این سؤالات را داشته باشد:

- چه واحدهایی آزاد، رزرو یا پیش‌فروش‌شده‌اند؟
- هر مشتری چقدر پرداخت کرده و چقدر مانده دارد؟
- قسط این ماه چه کسی سررسید است؟ چه کسی معوق دارد؟
- امروز باید با چه کسی تماس بگیرم؟

## قابلیت‌ها (نسخه ۰.۵.۰)

| بخش | توضیح |
| --- | --- |
| ⚡ **صفحه‌ی سریع (خانه)** | دکمه‌های بزرگ گرادیانی «فایل جدید» و «مشتری جدید»، آمار کلی، پیگیری‌های امروز و «آخرین مکالمات» — طراحی بازی‌گونه و یک‌ضربه‌ای |
| 🚀 **ثبت از انتخاب واحد** | هر ثبت جدید با «از کجا شروع کنیم؟» شروع می‌شود: انتخاب واحد آماده یا واحد پیش‌فروشی (و برای مشتری، فایل پیش‌فروش) |
| 🏠 **واحدهای آماده + پیوست‌ها** | تب «واحدها» برای مرور همه‌ی واحدها (با فیلتر وضعیت/پروژه) + افزودن **فایل/عکس/ویدیو** به هر فایل پیش‌فروش و هر واحد با پیش‌نمایش داخل برنامه |
| 🏷 **نوع فایل: واحد آماده / پیش‌فروش** | در ثبت سریع، «فایل جدید» دو گزینه دارد: واحد آماده (فقط واحدهای آزاد) یا پیش‌فروش؛ نوع روی فایل ذخیره و نمایش داده می‌شود |
| 📐 **متراژهای پروژه** | پروژه‌های چند متراژ: هر متراژ واریزی، امتیاز، قیمت کل و شرایط اقساط مخصوص خودش؛ هنگام ثبت فایل، انتخاب متراژ خودکار پرسیده و شرایطش پر می‌شود |
| 💹 **سهامی با واریزی/امتیاز** | پروژه‌های سهامی هم می‌توانند واریزی، امتیاز و قیمت حدودی کل داشته باشند + نمایش «مجموع واریزی + امتیاز» |
| ✅ **پرداخت خودکار اقساط** | با رسیدن به تاریخ سررسید قسط پیش‌رو، قسط به‌صورت خودکار از بخش اقساط پاک و به واریزی پروژه اضافه می‌شود (هر روز + هنگام استارت) |
| ⚡ **ثبت سریع فایل** | پروژه یک‌بار کامل تعریف می‌شود؛ در ثبت فایل فقط فیلدهای خالی (مالک، امتیاز، رتبه) پرسیده می‌شوند و «قیمت کل = واریزی + امتیاز» همیشه به‌صورت زنده محاسبه می‌شود |
| 🏗 **پروژه‌ها** | مشخصات فنی، مجوزها، پیشرفت فیزیکی، بودجه، قیمت تمام‌شده و قیمت فروش هر متر + پیش‌فرض‌های ثبت فایل |
| 🏢 **واحدها** | بلوک، طبقه، متراژ، جهت، امکانات، قیمت‌گذاری و وضعیت — از داخل پروژه‌ها + ساخت گروهی واحد |
| 👤 **مشتری‌ها** | خریدار/فروشنده‌ی هر فایل: نقش، وضعیت مذاکره، اتصال به فایل/واحد، تماس تلفنی، پیگیری‌ها و مکالمات اختصاصی |
| 💬 **مکالمات و نوت‌های تاریخ‌دار** | ثبت پیگیری و **نتیجه‌ی مکالمات** با مشتری/فروشنده با تاریخ شمسی، نوع مکالمه و نتیجه — تایم‌لاین روی هر فایل و هر مشتری + مرور کلی |
| 📄 **پیش‌فایل‌ها** | فایل پیش‌فروش: شماره‌گذاری خودکار، اسنپ‌شات واحد، رتبه، شرایط فروش، اقساط و قیمت کل |
| 🔔 **پیگیری‌ها با آلارم** | تماس، بازدید، جلسه و یادآوری با تاریخ/ساعت — **آلارم دقیق** در لحظه‌ی سررسید + اتصال مستقیم به مشتری |
| 📤 **خروجی اکسل/بکاپ** | بکاپ کامل JSON (قابل بازیابی، شامل مشتریان و مکالمات) + خروجی CSV پیش‌فایل‌ها |
| 🔄 **آماده برای سرور** | هر رکورد وضعیت همگام‌سازی دارد؛ افزودن سرور در آینده بدون تغییر صفحه‌ها |
| 🌙 **ظاهر** | فونت وزیرمتن، تاریخ شمسی، راست‌چین کامل |

## نصب سریع

### ۱) ساخت APK از سورس

```bash
git clone <repo-url> pish-file
cd pish-file

# مسیر SDK اندروید را تعیین کنید
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

# ساخت نسخه آزمایشی
./gradlew assembleDebug

# فایل خروجی
# app/build/outputs/apk/debug/app-debug.apk
```

### ۲) نصب روی گوشی

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

نیازمندی‌ها: **Android 8.0 (API 26)** و بالاتر، JDK 17+، Android SDK 35.

## ساختار پروژه

```
app/src/main/java/ir/pishfile/app/
├── core/            # ابزارها: تاریخ شمسی، قالب‌بندی مبالغ، ثابت‌ها، بکاپ
├── data/
│   ├── local/       # Room: موجودیت‌ها (۶ جدول) و DAOها
│   ├── repository/  # منطق کاری: پیش‌فایل، پروژه، واحد، مشتری، تنظیمات
│   └── sync/        # قراردادهای همگام‌سازی (آماده برای سرور)
├── di/              # ظرف وابستگی‌ها (بدون کتابخانه خارجی)
└── ui/
    ├── components/  # کامپوننت‌های مشترک فارسی
    ├── navigation/  # گراف صفحه‌ها و نوار پایین
    ├── screens/     # داشبورد، پروژه، واحد، مشتری، پیش‌فایل، اقساط، پیگیری، تنظیمات
    ├── theme/       # رنگ، تایپوگرافی (وزیرمتن)، تم راست‌چین
    └── viewmodel/   # فرم‌ها و وضعیت هر صفحه
```
