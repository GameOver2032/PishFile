# نسخه‌های آماده‌ی نصب

## PishFile-0.1.0-debug.apk

فایل نصب نسخه‌ی آزمایشی (نسخه‌ی ۰.۱.۰ — فاز اول: هسته‌ی آفلاین).

**نصب:**

1. فایل APK را روی گوشی اندروید (۸.۰ و بالاتر) کپی کنید.
2. روی فایل بزنید؛ اگر پیام «نصب برنامه‌های ناشناس» آمد، اجازه دهید.
3. برنامه با نام **پیش‌فایل** در فهرست برنامه‌ها ظاهر می‌شود.

**نکته‌ها:**

- این نسخه **debug** است (شناسه‌ی `ir.pishfile.app.debug`) و برای تست و استفاده‌ی شخصی ساخته شده است.
- امضای آن کلید آزمایشی اندروید است؛ برای انتشار در بازار یا گوگل‌پلی باید با کلید اختصاصی امضا شود — [`docs/RELEASE.md`](../docs/RELEASE.md).
- با نصب این نسخه، یک **پروژه‌ی نمونه** ساخته می‌شود تا کارکرد برنامه را ببینید (قابل حذف).
- داده‌ها فقط روی همان گوشی ذخیره می‌شوند؛ از بخش تنظیمات بکاپ بگیرید.

**این APK چه چیزی دارد:**
پروژه‌ها با فیلدهای فنی و مجوزها، واحدها با متراژ/جهت/امکانات، مشتریان با اعتبارسنجی،
پیش‌فایل با شماره‌گذاری خودکار و ساخت خودکار اقساط، ثبت پرداخت، اقساط و معوقات،
پیگیری‌ها، داشبورد مالی، بکاپ JSON و خروجی اکسل CSV.

./gradlew assembleDebug
